# 📈 Stock Price Analyzer

## 📌 Project Overview
Stock Price Analyzer is a simple Java-based project that stores and analyzes stock prices using **Arrays, Sorting, and Binary Search**.

The project allows users to enter stock prices for a given number of days and perform different operations through a menu-driven program.

## 🎯 Objectives
- To understand the use of arrays in Java.
- To implement sorting algorithms.
- To perform searching using Binary Search.
- To find the maximum and minimum stock prices.
- To calculate the average stock price.
- To understand basic Data Structures and Algorithms.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Concepts:** Array, Sorting, Binary Search
- **IDE:** VS Code / IntelliJ IDEA / Eclipse

## ✨ Features
1. Enter stock prices for multiple days.
2. Display all stock prices.
3. Sort stock prices in ascending order.
4. Search for a stock price using Binary Search.
5. Find the maximum stock price.
6. Find the minimum stock price.
7. Calculate the average stock price.
8. Exit the program.

## ⚙️ Data Structures and Algorithms
- **Array:** Stores stock prices.
- **Bubble Sort:** Arranges stock prices in ascending order.
- **Binary Search:** Searches for a particular price in a sorted array.
- **Linear Traversal:** Finds maximum and minimum prices and calculates the average.

## ▶️ How to Run the Project

**Step 1:** Install Java JDK on your computer.

**Step 2:** Download or clone this repository.

```bash
git clone https://github.com/your-username/Stock-Price-Analyzer.git
```

**Step 3:** Open the project folder in your IDE.

**Step 4:** Compile the Java file.

```bash
javac StockPriceAnalyzer.java
```

**Step 5:** Run the program.

```bash
java StockPriceAnalyzer
```
